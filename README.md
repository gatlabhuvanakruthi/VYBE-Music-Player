# 🎵 Music Player

A simple and aesthetic music player web app built using **HTML, CSS, and JavaScript**.

## ✨ Features

* 🎶 Play and pause songs
* ⏭️ Next and previous song controls
* 🎧 Custom song collection
* 🎤 Displays song title and artist
* 🎨 Simple and aesthetic interface
* 🔊 Browser-based music playback

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Music-Player/
│
├── index.html
├── style.css
├── script.js
├── music/
│   ├── Dynamite.mp4
│   ├── Mad Woman.mp4
│   └── ...
│
└── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Make sure the music files are inside the `music` folder.
3. Open `index.html` in your browser.
4. Choose a song and enjoy! 🎧

## 🎯 Purpose

This project was created to practice **HTML, CSS, JavaScript, DOM manipulation, and audio playback** while building a fun and interactive music player.
